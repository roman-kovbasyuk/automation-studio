# Website creation

[Product recipes](/workflow) · **Status:** Persisted recipe authoring and simulation; live runtime and renderer planned.

Turn a site brief into a responsive website preview with a defined handoff.

[Open Product recipes →](http://127.0.0.1:5181/mvp/admin/recipes?demoRole=admin#admin-product-recipes) — select **Website creation**. Save, validate, simulate and publish its definition. The initial policy asks for brief, pages, primary action and content when absent. Simulation does not generate or deploy a website.

## Inputs and outcome

**Inputs:** audience, conversion goal, required pages/sections, source content, links, selected template and published application-managed design context.

**Proposed steps:** site brief → plan sections → bind approved design context → compose → validate → preview and handoff.

**Intended outcome:** the agreed pages and responsive states, working configured interactions, and preview/export artifacts. Exact delivery formats remain open.

## Clarification points

Ask for the primary conversion action, required sections, one page versus multiple pages, brand/template choice and final content approver when these choices are missing.

Public deployment is a separate outcome from preview/export and needs its own explicit scope. The recipe must check links, content fit and responsive behavior before handoff.
